About Me

Hello! I'm Mani Vardhan Satha, an Embedded Systems Engineer passionate about designing and building reliable hardware-software systems. I specialize in firmware development, IoT device integration, and Linux-based embedded platforms like OpenWRT.

My background in electronics & communication allows me to work across the stack—from sensor interfacing and peripheral programming to cloud communication and analytics.

Projects

OpenWRT IoT Gateway

Customized an OpenWRT router (MT7628AN) to support SSID, hotspot, LED control, sensor data reading via I²C/SPI, and sending data to IoT cloud using MQTT. Added basic web UI for configuration.

Minus Forty Freezer Monitoring

Worked on IoT-based freezer and refrigerator system. Migrated code to Python 3 and used Modbus over RS485 for sending commands and receiving data from the devices.

Wesko Smart Lock Updater

Worked on controlling smart locks via BLE using Python 3. Improved the firmware updater with MD5 checks, .pyc conversion, and rollback support for safer OTA updates.

Object Detection with OpenCV

Used OpenCV and Python to detect and track objects from webcam input using basic techniques like Haar cascades and thresholding.
